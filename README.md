# 📚 Sistema de Gerenciamento de Biblioteca

Aplicação web desenvolvida em **Python com Flask** para gerenciamento de uma biblioteca, permitindo o cadastro e controle de leitores, livros e empréstimos de forma simples e organizada.

---

## ✨ Visão Geral

Este projeto foi desenvolvido como parte do meu **processo de retorno ao desenvolvimento de software**, em paralelo ao curso de **Análise e Desenvolvimento de Sistemas**.

O objetivo principal é aplicar, na prática, conceitos de **desenvolvimento web**, **organização de código**, **persistência de dados** e **boas práticas**, por meio de uma aplicação funcional e evolutiva.

---

## 🎯 Objetivos do Projeto

- Consolidar conhecimentos em **Python e Flask**
- Desenvolver um sistema web completo, do back-end ao front-end
- Praticar modelagem de dados e operações CRUD
- Criar um projeto real para portfólio profissional

---

## ⚙️ Funcionalidades

- Cadastro, edição e exclusão de leitores
- Cadastro e gerenciamento de livros
- Controle de empréstimos e devoluções
- Upload de foto para leitores
- Autenticação de usuários (login e logout)
- Interface web simples e funcional

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Flask**
- **SQLAlchemy**
- **SQLite**
- **HTML5**

- **JavaScript**
- **Jinja2**
